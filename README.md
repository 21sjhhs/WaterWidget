# 喝水小组件

一个轻量 macOS 桌面小组件，用于记录每天喝水量。数据按日期保存在本机 `UserDefaults`。

## 功能

- 快捷记录 `50 / 100 / 250 / 350 / 500 ml`
- 自定义单次水量，支持调整到 `0 ml`，滚轮慢速调整时最小变化为 `1 ml`
- 点击自定义水量数字后，可用鼠标滚轮非线性调整；点击打勾记录后停止滚轮调整
- 主窗口支持“当前 / 水杯”两个界面切换
- 水杯界面支持按水杯视觉水位自动计算饮水量
- 水杯有“液面下降”和“直接水量”两种记录模式
- “液面下降”模式可先开启“设定液面”，校准完成后关闭；喝水时滚轮只能降低液面
- “直接水量”模式可自由上下调节液面，当前液体体积就是本次喝水量
- 水杯水位可点击杯子后用鼠标滚轮调整
- 水杯体积按杯型轮廓分层，用旋转截面 `πr²` 积分后按容量换算
- 水杯设定窗口支持杯型预设、容量、杯口、杯身、杯底、水杯高度、杯肚位置、弧度、圆润程度等参数设计
- 设置每日目标
- 点击记录入口可打开更大的记录管理窗口
- 在记录管理窗口中修改、删除或清空今日记录
- 桌面模式：停在桌面图标上方、普通窗口下方
- 置顶模式：浮在普通窗口上方
- 菜单栏入口：隐藏后可从菜单栏水滴图标重新显示

## 运行

```bash
swift run -c release WaterWidget
```

## 打包成 App

```bash
chmod +x scripts/package_app.sh
./scripts/package_app.sh
open build/WaterWidget.app
```

生成的应用位于：

```text
build/WaterWidget.app
```

如果想开机自动显示，可以在 macOS 的“系统设置 > 通用 > 登录项”里添加这个 App。
